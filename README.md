# MCP Idle Game

Идл-игра, в которой играет LLM-агент. Агент подключается по MCP как клиент,
ставит активное действие, добывает ресурсы, крафтит, продаёт, качает скиллы,
бьёт монстров, выполняет квесты и делает престиж. Наблюдатель смотрит на ту же
игру через дебаг-страницу.

Стек: Node.js 24, TypeScript (ESM, strict), чистая архитектура, `node:sqlite`,
`@modelcontextprotocol/server`, `zod`, `neverthrow`.

## Быстрый старт

```sh
npm install
npm run build
npm start
```

Сервер поднимается на `http://127.0.0.1:3000`, печатает API-ключ один раз и
создаёт дефолтного игрока. Дальше:

- `http://127.0.0.1:3000/mcp` — точка входа MCP (Streamable HTTP);
- `http://127.0.0.1:3000/` — дебаг-страница с состоянием игры.

Для разработки: `npm run dev` (запуск TS напрямую через strip-types, с
перезапуском при изменениях).

## Подключение MCP-клиента

Ключ передаётся заголовком `Authorization: Bearer <key>`. Фолбэк — заголовок
`X-API-Key`. Параметр `?key=` работает только в dev-режиме.

```json
{
  "mcpServers": {
    "idle-game": {
      "type": "http",
      "url": "http://127.0.0.1:3000/mcp",
      "headers": {
        "Authorization": "Bearer mcp_live_..."
      }
    }
  }
}
```

Клиент видит 13 инструментов: `game_state`, `game_action`, `game_craft`,
`game_upgrades`, `game_trade`, `game_bank`, `game_combat`, `game_quests`,
`game_market`, `game_skills`, `game_prestige`, `game_log`, `game_tick`, плюс
ресурсы `game://state`, `game://skills`, `game://market`, `game://quests` и
промпт `game_strategy`.

Запрос без ключа отклоняется с 401, с неверным или отозванным ключом — с 403.

## Ключи

```sh
npm run keys -- create --label "ноутбук"   # печатает ключ один раз
npm run keys -- list                        # игроки и их ключи
npm run keys -- revoke --id <key id>        # отзыв ключа
```

В базе лежит только SHA-256 хэш ключа и его префикс `mcp_live_xxxx`. Ключ с
scope `read` может только читать состояние, с `play` — ещё и менять игру.

## Дебаг-страница

`/` отдаёт статику из каталога `public/`: кошелёк, активное действие с
прогрессом, скиллы, инвентарь, апгрейды с ценами и кнопкой «Купить», рынок,
квесты, лента событий. Данные приходят из `GET /api/state`, действия — из
`POST /api/action`. Страница обновляется раз в две секунды и показывает, чей это
игрок. Ключ с правами `read` получает страницу без кнопок мутаций.

## Баланс и симулятор

Числа игры лежат в `content/`, а не в коде. Симулятор прогоняет прогрессию через
чистый тик и считает метрики: время до престижа, доход по этапам, долю простоя,
окупаемость апгрейдов, узкие места.

```sh
npm run sim -- 24                     # прогон на 24 часа, печатает метрики
npm run autotune                      # подбор кривых, пишет content/balance.json
```

Критерии баланса: апгрейд окупается за 3–15 минут, престиж доступен через 2–6
часов, простой не занимает больше 60% времени.

## Структура

```sh
src/
  domain/         чистое ядро: состояние, кривые, тик, скиллы, квесты, престиж
  application/    сценарии и порты (репозитории, часы, контент)
  infrastructure/ node:sqlite, контент и zod-схемы, MCP-сервер, HTTP, симулятор
  bootstrap/      composition root, CLI ключей, симулятор, автотюн
content/          данные игры: скиллы, предметы, рецепты, апгрейды, зоны, квесты
public/           дебаг-страница
tests/            node:test: домен, use cases, инфраструктура, интеграция, e2e
```

Домен и application не знают про MCP, HTTP, SQLite и таймеры. `tick(state, now)`
— чистая функция: вся мутабельность возвращается новым состоянием. Время и
случайность идут через порты, тик детерминирован по seed из состояния.

## Переменные окружения

| Переменная         | По умолчанию  | Назначение                     |
| ------------------ | ------------- | ------------------------------ |
| `MCPG_PORT`        | `3000`        | порт HTTP-сервера              |
| `MCPG_HOST`        | `127.0.0.1`   | адрес привязки                 |
| `MCPG_DATA_DIR`    | `./data`      | каталог файла базы             |
| `MCPG_CONTENT_DIR` | `./content`   | каталог данных игры            |
| `MCPG_PUBLIC_DIR`  | `./public`    | каталог статики дебаг-страницы |
| `MCPG_ENV`         | `development` | `production` отключает `?key=` |
