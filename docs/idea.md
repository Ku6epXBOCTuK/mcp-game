# Проект: AI-Native Idle Game (MCP + Generative UI)

## 💡 Суть идеи

Создать изолированную idle-игру (кликер/симулятор экономики), где игроками являются ИИ-агенты, взаимодействующие с игровым движком через протокол **MCP (Model Context Protocol)**. При этом ИИ не просто играет под капотом, а **динамически генерирует и обновляет веб-интерфейс (HTML/CSS)** для человека-наблюдателя, отражая свой прогресс и "характер".

---

## 🛠 Архитектура проекта

1. **Движок игры (Бэкенд):** Скрипт, который хранит состояние (ресурсы, постройки, логику прироста) и обновляет их во времени.
2. **MCP-Сервер:** Мост между движком и ИИ.
   - _Ресурсы (Resources):_ `game_state` (JSON с текущим балансом).
   - _Инструменты (Tools):_ `buy_upgrade()`, `collect_resources()`, а также специальный инструмент `update_dashboard(html_code)`.
3. **ИИ-Игрок (Агент):** Раз в цикл анализирует экономику, принимает решение о покупке и генерирует новый HTML-код дашборда.
4. **Веб-клиент (Фронтенд):** Простая страница, которая отображает HTML-шаблон, присланный нейросетью.

---

## 🎯 В чём реальная ценность (Практическое применение)?

- **Generative UI (Главная фишка):** Исследование горячего тренда, когда ИИ создает интерфейсы «на лету» под контекст ситуации. Каждая модель (Claude, GPT, Gemini) создаст UI в своем уникальном стиле.
- **Безопасная песочница для ИИ-агентов:** Идеальный полигон (R&D-стенд) для тестирования долгосрочного планирования, логики и автономности агентов в меняющейся среде без риска для реальных систем.
- **LLM-Бенчмарк:** Наглядное соревнование моделей. Кто эффективнее управляет ресурсами и стабильнее работает с MCP без "галлюцинаций" на длинной дистанции.
- **Медийный / Вирусный потенциал:** Готовый формат для стримов на Twitch ("ИИ играют в экономику и сами строят под это сайты") или популярного Open-Source репозитория для обучения разработчиков работе с MCP.

---

## 🚀 План для MVP (Минимальный продукт)

1. Написать простейшую экономику на Python/TS (золото капает само, есть 3 апгрейда).
2. Создать инструмент `update_dashboard` для сохранения строки с HTML.
3. Подключить LLM через MCP-клиент и дать промпт: _"Играй эффективно и обновляй HTML-страницу для человека, меняя дизайн под игровое состояние"_.
